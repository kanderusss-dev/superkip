What even IS superkip???:

Superkip is a tool, for scanning IP, or domains.
Superkip only needs domain or ip address, and that's it!
It get's every opened port, every port with response, WHOIS data and ipinfo.
That's a lot of information!
Just make sure you know how to use it.
Example of superkip working:

In: Enter host: google.com
In: Enter ports (optional, e.g. 21 443): 8080 21 443
In: Enter an output query (optional, e.g. GET or HEAD): GET

Out: It might take some time to get information...
Out: DEBUG: Getting open ports / with response...
Out: DEBUG: Getting info from IP (ipinfo.io)...
Out: DEBUG: Getting info from IP (api.ipapi.is)...
Out: DEBUG: Getting WHOIS data...

Out: It took 5 seconds to get information.

...information here...



How to use:

Step 1: Requirements:
Make sure you have python downloaded,
And install requirements.
Install like this:
On windows:
pip install -r requirements.txt
Linux/macOs version:
pip3 install -r requirements.txt

Step 2: Getting host:
Enter domain, for example: google.com
By the way, you can also type IPs in there, like 127.0.0.1 or 8.8.8.8

Step 3: Getting ports:
Enter ports, for example: 8080 443 21 23 53
Ports are optional, you don't actually have to type anything in there.

Step 4: Getting query:
Enter query, for example: GET
But PLEASE, don't type any POST queries, superkip doesn't work for 'em.

Step 5: Result:
Just wait for a couple of seconds.
And you will get everything.

Step 6: Enjoy it!:
Enjoy superkip!
